# Streamana

Streamana is a retro Y2K-inspired watch together platform that allows multiple users to watch videos in sync in realtime.

---

## Features

- Realtime synchronized playback
- Room-based watch sessions
- YouTube video support
- MP4/custom video URL support
- Synced play, pause, and seek
- Multiplayer room system
- Retro pastel Y2K interface
- Socket.IO realtime communication

---

## Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express
- Socket.IO

---

## Installation

### Clone the repository

```bash
git clone https://github.com/your-username/streamundi.git
```

---

## Frontend Setup

```bash
cd client
npm install
npm run dev
```

---

## Backend Setup

```bash
cd server
npm install
node index.js
```

---
